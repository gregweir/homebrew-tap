Greg Weir's Homebrew tap

Formulae maintained by the author of [homeHash](https://github.com/gregweir/homeHash),
the lightweight local-only Bitcoin miner monitor:

```sh
brew tap gregweir/tap
brew install homehash
```

Or in one step: `brew install gregweir/tap/homehash`

Or in a `brew bundle`:

```ruby
tap "gregweir/tap"
brew "homehash"
```
